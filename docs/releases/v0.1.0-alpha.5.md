[Alpha.6](https://github.com/SuperWes/retro-bit-2.4-wireless-pro-controller-polymega-custom-firmware/releases/tag/v0.1.0-alpha.6) adds the optional SEGA preset, validated offline and pending hardware testing. The original assets below are unchanged.

Use **Retro-Bit's official updater** to install the custom firmware. **A Windows
PC is required.** The download now contains just the ready-made `.bxw` firmware
and a short `README.txt`; no project installation script is needed.

1. Download and extract **retrobit-polymega-v0.1.0-alpha.5.zip** below.
2. Download and fully extract [Retro-Bit's official V2 USB Pro 1.1 package](https://retro-bit.com/sitepad-data/uploads/2025/07/V2-USB-Receiver-Pro-Controller-1.1-Firmware-Switch-2-Compatibility.zip).
3. Follow its installation PDF and run **BxUsbUpdate.exe** from **Update Program**,
   keeping the DLLs alongside it. Select this release's
   **retrobit_usb_pro_1.1_polymega_toggle_EXPERIMENTAL.bxw** in place of the official
   firmware. Wait for the update to finish before disconnecting.
4. **Re-sync the receiver with the controller after updating.**

**The firmware itself is unchanged.** An already working receiver does not need
another flash. Its SHA-256 is
`b3f78325ae7de66e7f416fc9f55a4b191a507c2025790d8caa64157aebc5e935`.

Hold **Start + D-pad Right**, then release, to swap C and Z. Repeat to switch back.
Stock mapping returns when the receiver is reconnected. ZL/ZR remain Saturn L/R;
duplicate L/R buttons follow C/Z. Use two green lights on Polymega (three on Mac).
Enable Analog in Polymega's own settings for analog games.
