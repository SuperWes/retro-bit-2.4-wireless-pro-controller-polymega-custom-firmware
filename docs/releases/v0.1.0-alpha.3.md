Corrects the instructions: the working USB mode shows **two green lights on
Polymega** and **three on Mac**. The firmware and installer behavior are unchanged;
there is no need to reflash an already working receiver.

Download **retrobit-polymega-v0.1.0-alpha.3.zip**, extract it on Windows 10/11, and
run **Install.cmd**. It downloads the official files, applies the patch locally,
and opens the updater. Follow the PDF in the generated **Firmware Package**
folder and select the `.bxw` from its **Firmware** folder.

Hold **Start + D-pad Right**, then release, to toggle C/Z. Reconnecting the USB
receiver resets to stock mapping. ZL/ZR remain Saturn L/R. For analog games,
enable Analog in Polymega's in-game controller settings.
