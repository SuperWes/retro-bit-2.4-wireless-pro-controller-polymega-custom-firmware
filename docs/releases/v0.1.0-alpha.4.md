Adds the required post-update step: **re-sync (pair) the receiver with the
controller before playing**. Firmware is unchanged; an already working receiver
does not need another flash.

On Polymega, stock mapping has **C and Z reversed**. **Start + D-pad Right**
(hold, then release) toggles only that swap. The rest of the stock mapping is
preserved; the duplicate L/R buttons follow C/Z. ZL/ZR remain Saturn L/R.
Reconnecting the receiver restores stock mapping. Use **two green lights on
Polymega** (**three on Mac**), and enable Polymega's Analog setting for analog games.

The same receiver may help other USB hosts with reversed C/Z in XInput or PS3
mode; those hosts are untested.

Download **retrobit-polymega-v0.1.0-alpha.4.zip**, extract on Windows 10/11, and
run **Install.cmd**. It downloads the official files, patches locally, and opens
the updater. Follow the PDF in **Firmware Package**, select the `.bxw` from
**Firmware**, wait for the update to finish, then re-sync.

**USE AT YOUR OWN RISK. V2 USB receiver only.** Unofficial firmware supplied AS IS
without warranty; flashing can brick the receiver and recovery is not guaranteed.
[Full notice](https://github.com/SuperWes/retro-bit-2.4-wireless-pro-controller-polymega-custom-firmware/blob/v0.1.0-alpha.4/USE_AT_YOUR_OWN_RISK.txt).
