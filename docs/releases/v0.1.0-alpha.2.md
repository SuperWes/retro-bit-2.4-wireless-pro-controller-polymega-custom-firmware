Download **retrobit-polymega-v0.1.0-alpha.2.zip**, extract it on Windows 10/11, and
double-click **Install.cmd**. Internet access is required. The installer obtains
Retro-Bit's official files, patches locally, and opens the updater. Follow the
PDF in the generated **Firmware Package** folder and select its **Firmware** file.

Hold **Start + D-pad Right**, then release, to toggle C/Z. Stock mapping remains
the default at receiver startup. ZL/ZR stay Saturn L/R. Enable Analog in
Polymega's settings for analog games.

**USE AT YOUR OWN RISK. V2 USB receiver only.** Unofficial firmware supplied AS IS
without warranty; flashing can brick the receiver and recovery is not guaranteed.
[Full notice](https://github.com/SuperWes/retro-bit-2.4-wireless-pro-controller-polymega-custom-firmware/blob/v0.1.0-alpha.2/USE_AT_YOUR_OWN_RISK.txt).

This is the same firmware as alpha.1, with a simpler installer and documentation.
One user reported successful installation and toggle operation on Polymega.
See the [hardware report](https://github.com/SuperWes/retro-bit-2.4-wireless-pro-controller-polymega-custom-firmware/blob/v0.1.0-alpha.2/docs/polymega-hardware-results.json)
and [offline validation](https://github.com/SuperWes/retro-bit-2.4-wireless-pro-controller-polymega-custom-firmware/blob/v0.1.0-alpha.2/firmware/start-right-toggle/validation.json).

The release ZIP contains only project files. Vendor firmware, updater, DLLs, and
manuals are downloaded directly from Retro-Bit during setup.
