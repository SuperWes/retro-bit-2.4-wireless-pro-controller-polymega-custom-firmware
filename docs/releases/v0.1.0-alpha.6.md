Adds **SEGA layout on Start + Up** alongside **Street Fighter layout on Start + Right**. Stock remains the startup default.

- **Street Fighter:** the existing C/Z-only swap.
- **SEGA:** relative to Street Fighter, move the actions on X/A/B to A/B/C, and C's action to X. Y, Z, ZL and ZR keep their Street Fighter outputs.
- Hold the shortcut, then release. Repeat the active shortcut for stock; the other selects its preset directly. They do not stack. Reconnecting the receiver restores stock.

**New firmware: validated offline, not yet flashed or tested on hardware.** The earlier C/Z-only image was reported working in a fighting game, but did not correct Nanatsu Kaze no Shima Monogatari. These are manual layouts, not automatic game detection. Evercade and other hosts are untested.

### Install

**A Windows PC is required.** The ZIP contains only the ready-made `.bxw` and `README.txt`.

1. Download and extract **retrobit-polymega-v0.1.0-alpha.6.zip** below.
2. Download and fully extract [Retro-Bit's official V2 USB Pro 1.1 package](https://retro-bit.com/sitepad-data/uploads/2025/07/V2-USB-Receiver-Pro-Controller-1.1-Firmware-Switch-2-Compatibility.zip).
3. Follow its installation PDF and run **BxUsbUpdate.exe** from **Update Program**, keeping its DLLs alongside it. Choose this release's **retrobit_usb_pro_1.1_polymega_toggle_EXPERIMENTAL.bxw** instead of the official firmware. Wait for the update to finish before disconnecting.
4. **Re-sync the receiver with the controller after updating.** Use two green lights on Polymega (three on Mac). Enable Analog in Polymega's settings for analog games.
