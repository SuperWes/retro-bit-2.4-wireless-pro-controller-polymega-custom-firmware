First stable release of the **Street Fighter** and **SEGA** layouts for the Retro-Bit Saturn 2.4 GHz Wireless Pro controller's **V2 USB receiver on Polymega**.

Both layouts have been tested and reported working on the author's receiver with Polymega.

| Hold, then release | Layout |
| --- | --- |
| **Start + D-pad Right** | **Street Fighter:** exchange C and Z. |
| **Start + D-pad Up** | **SEGA:** from Street Fighter layout, move X/A/B actions to A/B/C and C's action to X. |

Stock is the startup default. The other shortcut selects its layout directly; the changes do not stack. Repeat the active shortcut or reconnect the receiver to restore stock. Analog reports and ZL/ZR outputs are preserved.

### Install

**A Windows PC is required.** Download and extract **retrobit-polymega-v1.0.0.zip** below. It contains only `retrobit_usb_pro_1.1_polymega.bxw` and `README.txt`.

1. Download and fully extract [Retro-Bit's official V2 USB Pro 1.1 package](https://retro-bit.com/sitepad-data/uploads/2025/07/V2-USB-Receiver-Pro-Controller-1.1-Firmware-Switch-2-Compatibility.zip).
2. Follow its installation PDF and run **BxUsbUpdate.exe** from **Update Program**, with its DLLs alongside it. Select this release's custom `.bxw` instead of the official firmware. Wait for the update to finish before disconnecting.
3. **Re-sync the receiver with the controller after updating.** Use USB mode with two green lights on Polymega (three on Mac). Enable Analog in Polymega's settings for analog games.
